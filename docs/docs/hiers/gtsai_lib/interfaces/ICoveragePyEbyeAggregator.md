# Interface `ICoveragePyEbyeAggregator`
Represents an aggregator for statement coverage data generated by coverage.py,
which corresponds to entity-level statement coverage metric.

A JSON file is generated, and the aggregated data is returned in the following format:

	- A list of JSON dictionaries, each containing:

		* "module" (str): The name of the module, specified as a "dotted path" starting from the Focal Project Root Path, to which the standalone entity whose coverage percentage is being evaluated belongs.
		* "class" (str): The name of the class, if any, to which the standalone entity belongs. If the entity is a function, this field is an empty string
		* "entity" (str): The name of the standalone code entity for which the coverage percentage is evaluated
		* "coverage" (float): The measured coverage percentage, as a `float` between 0 and 1 inclusive, for the specified standalone entity


!!! ext-points "Extension Points"
	
	- The format of the "coverage.py" report being processed is specified by the descendants of this interface
	

!!! abstract "Details"
	- **Fully-qualified Name**: `calc_coverage.covpy_ebye_aggr.ICoveragePyEbyeAggregator`
